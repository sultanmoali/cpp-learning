# Simple Calculator

## What does it do?
A basic calculator that performs arithmetic operations.

## How it works:
1. User enters first number
2. User selects an operator (+ - * /)
3. User enters second number
4. Program calculates and shows result

## Concepts used:
- if / else if
- arithmetic operations
- input/output
- basic error handling (division by zero)

## Example:
Input: 10 + 5  
Output: 15
