# Odd or Even Checker

## What does it do?
This program checks whether a number is odd or even.

## How it works:
1. User enters a number
2. Program checks if the number is divisible by 2
3. Displays "Odd" or "Even"

## Concepts used:
- if / else
- modulo operator (%)
- input/output

## Example:
Input: 7  
Output: Odd
